\# 🛡️ AegisOps — AI-Powered DevOps Incident Response System



AegisOps is an AI-powered DevOps incident response system that automatically analyzes server logs, detects potential incidents, classifies their severity, and uses Google Gemini AI to generate a professional incident investigation report.



\## 🚀 Features



\- 🔎 Automatic server log monitoring

\- 🚨 Incident detection

\- 🔐 Security incident classification

\- 🌐 Web server incident detection

\- ⚠️ Severity classification

\- 🤖 AI-powered incident investigation using Google Gemini

\- 📋 Automated incident reports

\- 🐳 Docker containerization

\- 🔐 Secure API key management using environment variables

\- 🐙 Git/GitHub version control
